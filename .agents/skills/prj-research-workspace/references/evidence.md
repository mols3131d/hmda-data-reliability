# Evidence

출처가 충돌하거나 근거 품질, 분류 또는 추적성 판단이 필요할 때 읽습니다.

## Evidence Classes

| 종류 | 의미 |
| --- | --- |
| **권위 근거(Authoritative)** | 원하는 동작이나 제약을 정의합니다. |
| **관찰 근거(Observed)** | 코드, 설정, 테스트 또는 실행 결과에서 직접 확인했습니다. |
| **보조 근거(Supporting)** | 역사와 외부 맥락을 제공합니다. |
| **가정(Assumption)** | 아직 검증되지 않은 해석입니다. |

낮은 우선순위의 근거가 높은 우선순위의 근거를 조용히 덮어쓰지 않도록 합니다.

## Source Quality

- 현재 환경에서 직접 관찰한 코드·설정·테스트·실행 결과를 우선합니다.
- 외부 사실은 공식 문서, 표준, 원 논문과 같은 1차 자료를 우선합니다.
- 최신 문서라도 실제 설치 버전과 환경이 다르면 그대로 적용하지 않습니다.
- 접근하지 못했거나 확인하지 못한 내용은 사실처럼 작성하지 않습니다.

## Traceability

중요한 결론에는 다시 확인할 수 있는 근거 위치를 남깁니다.

| Evidence | Locator example |
| --- | --- |
| 코드·설정 | `path:line` 또는 `path#symbol` |
| 테스트 | 테스트 파일과 테스트 이름 |
| 실행 결과 | 실행한 명령과 핵심 결과 |
| Git·Issue·PR | commit, issue 또는 PR 식별자 |
| 외부 자료 | 원문 URL과 적용 버전·날짜 |

근거 위치는 활동 기록이 아니라 결론을 검증하는 데 필요한 수준으로 제한합니다.

## Conflicts

충돌하는 근거는 임의로 합치지 않습니다. 다음을 구분하여 기록합니다.

- 무엇과 무엇이 충돌하는가
- 현재 답에 어떤 영향을 주는가
- 추가 조사나 결정이 필요한가

대표적인 충돌 처리:

| Conflict | Handling |
| --- | --- |
| 사용자 의도와 활성 명세 | 조용히 선택하지 않고 충돌을 드러냅니다. |
| 명세와 구현 | 현재 동작과 의도한 동작을 구분합니다. |
| 문서와 코드 | 코드를 현재 상태 근거로 사용하고 문서의 노후 가능성을 표시합니다. |
| 테스트와 의도 | 계약 충돌로 기록하고 임의 수정하지 않습니다. |
| 공식 문서와 설치 버전 | 실제 버전에 맞는 자료를 다시 확인합니다. |

## Evidence Economy

- 같은 사실을 뒷받침하는 근거를 불필요하게 반복하지 않습니다.
- 링크 목록보다 결론과 직접 연결된 근거를 우선합니다.
- 대용량 raw output 대신 재현 명령과 필요한 결과를 남깁니다.
- 비공개 추론이나 Chat transcript를 지속 가능한 근거로 저장하지 않습니다.
