# PR #245 Work Summary

## 한눈에 보기

이 PR은 데이터 문제를 검토하는 AI가 **필요한 근거를 보고, 사람의 다음 판단에 도움이 되는 의견을 내며, 그 품질을 다시 확인할 수 있도록** Review AI의 평가 기반을 만들었습니다. AI가 복구나 데이터 변경을 직접 실행하게 하는 작업은 아닙니다.

## 무엇을 만들었나

- **필요한 정보만 전달:** 문제와 관련된 자료를 골라 크기를 제한하고, 자료의 출처와 확인되지 않은 부분을 함께 기록합니다.
- **근거 밖의 주장을 차단:** AI가 참고할 수 있는 자료와 답변 검증기가 허용하는 자료를 맞춰, 없는 근거를 인용하거나 실제로 본 근거가 잘못 거부되는 일을 막습니다.
- **쓸모 있는 검토인지 확인:** 답변이 사실을 그대로 되풀이하거나, 구체적인 조치 없이 모호하게 회피하는 경우를 찾아내는 대조 사례를 둡니다.
- **변경 전후를 비교:** 같은 사례와 다섯 가지 사람 평가 기준으로 기존 답변과 변경된 답변을 비교하고, 결과와 판단 근거를 저장합니다.
- **오류와 변조를 막음:** 입력이 너무 크면 AI를 호출하기 전에 거부하고, 불완전하거나 서로 맞지 않는 평가 기록은 저장하지 못하게 합니다.

## 무엇이 달라지나

이제 AI 답변을 단순히 형식이 맞는지만 보는 대신, 근거를 벗어나지 않았는지와 사람의 판단에 보탬이 되는지를 정해진 사례와 기준으로 반복 점검할 수 있습니다. 최종 판단과 데이터 변경 권한은 계속 사람과 기존의 결정론적 절차에 남습니다.

## 알아둘 점

오프라인 테스트와 예시 비교는 평가 체계가 약속한 대로 작동하는지 확인합니다. 실제 모델이 현장에서 유용한지 또는 사람이 실제로 더 나은 결정을 내리는지까지 증명한 것은 아닙니다. 현재 구현 세부와 최신 검증 상태는 [20번 진행 보고서](20-report-review-ai-pr245-closure-status.md), 다음 closure 단계는 [19번 계획](19-plan-review-ai-pr245-closure/README.md)을 참고하세요.
