## First Action

**바로 시작할 일은 1번의 사례표 작성과 현재 사용처 대조입니다.** 예를 들어 100건이 그대로 100건인 경우에는 감소가 없습니다. 하지만 빈 값이 계속 많다면 품질 문제는 남아 있을 수 있고, 마지막 수집 시각이 같아도 시간이 지나면 오래된 데이터가 됩니다. 이 차이를 기존 탐지기와 품질 게이트가 어떻게 처리하는지 확인합니다.
