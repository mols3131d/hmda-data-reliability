# PR 252 Remaining Work Explained

**남은 핵심은 ‘아무 변화가 없는데도 울리는 경보’를 바로잡는 일입니다.** 기존 네 수정 단위는 구현·로컬 검증·독립 리뷰를 마쳤습니다. 이제 경보 기준을 `0`으로 설정했을 때의 의미를 확정하고, 그에 맞춰 탐지기를 수정해야 합니다.

## What Is Already Done

[PR #252](https://github.com/mols3131d/hmda-data-reliability/pull/252)는 도메인별 결함과 테스트의 빈틈을 찾아 실제로 수정하는 작업입니다.

| Area | Result |
| --- | --- |
| 데이터 적재 | 원본 열 순서가 바뀌어도 값이 다른 항목에 잘못 저장되지 않도록 수정했습니다. |
| AI 응답 처리 | 처리 한계를 넘는 응답도 정해진 실패 결과와 기록을 남기도록 수정했습니다. |
| 복구 상태 | 데이터 변경 후 정리 과정에서 실패해도, 이미 변경됐다는 사실을 보존하도록 수정했습니다. |
| AI 연결 테스트 | 실제 SDK가 보내는 요청을 검사해, 잘못된 요청도 테스트만 통과하는 빈틈을 보완했습니다. |

이 네 단위의 완료가 PR 전체의 완료를 뜻하지는 않습니다. 남은 탐지기 변경도 별도 검증이 필요합니다.

## Why An Unchanged Dataset Raises An Alarm

경보 기준은 **얼마나 나빠지면 알려줄지 정한 값**입니다. 예를 들어 감소 기준이 50%라면, 데이터가 100건에서 50건으로 줄었을 때 경보가 울립니다.

현재는 감소 기준에 `0`도 입력할 수 있습니다. 그런데 탐지기는 변화가 없는 경우도 ‘감소율이 0 이상’이라는 조건에 포함합니다. 빈 값 비율을 비교하는 규칙에도 같은 문제가 있습니다.

| Example | Current Behavior With Zero | Recommended Behavior With Zero |
| --- | --- | --- |
| 데이터 100건 → 100건 | 감소 경보 발생 | 변화가 없으므로 경보 없음 |
| 빈 값 비율 10% → 10% | 빈 값 증가 경보 발생 | 변화가 없으므로 경보 없음 |
| 데이터 100건 → 99건 | 감소 경보 발생 | 실제로 줄었으므로 경보 발생 |
| 빈 값 비율 10% → 11% | 빈 값 증가 경보 발생 | 실제로 늘었으므로 경보 발생 |

**문제는 기본 설정 전체가 아니라, 해당 기준을 `0`으로 지정한 경우에 있습니다.** 의미 없는 경보는 사용자가 정상 데이터까지 조사하게 만듭니다.

## Recommended Choice

**`0`은 계속 허용하되, 실제로 나빠진 경우에만 경보를 울리는 안을 권장합니다.** 이 안에서 `0`은 ‘조금이라도 나빠지면 알려줘’라는 뜻입니다. 변화가 없거나 좋아졌다면 이 두 규칙은 경보를 만들지 않습니다.

다른 선택은 `0` 입력을 금지하는 것입니다. 다만 지금 유효한 설정을 오류로 바꾸므로, 사용하는 쪽도 설정을 바꿔야 할 수 있습니다. 권장안은 기존 입력을 유지하면서 오경보를 고칠 수 있습니다. **아직 어느 쪽도 채택된 결정은 아닙니다.**

수정할 때는 경계값도 지켜야 합니다. 기준이 50%이고 데이터가 정확히 50% 줄었다면 기존처럼 경보가 울려야 합니다. 따라서 단순히 ‘기준과 같으면 모두 제외’하면 안 됩니다. 권장안의 조건은 다음 두 가지입니다.

1. 실제로 나빠졌는가?
1. 나빠진 정도가 설정한 기준 이상인가?

이 조건은 데이터 감소와 빈 값 증가에 적용합니다. 데이터가 얼마나 오래됐는지 판단하는 별도 규칙은 그대로 유지합니다.

## What Happens Next

1. **설정 의미 확정:** `0` 허용과 실제 악화만 탐지하는 권장안, 또는 `0` 금지 중 하나를 선택합니다.
1. **테스트와 최소 수정:** 무변화·악화·개선·기준과 정확히 같은 사례를 테스트로 고정하고, 명세 문구와 구현을 맞춥니다.
1. **완료 확인:** 변경 영향을 검증하고 독립 리뷰와 CI를 확인한 뒤 체크리스트와 PR 상태를 갱신합니다.

기존 네 수정 단위를 다시 구현할 필요는 없습니다. 남은 탐지기 변경의 검증까지 마쳐야 PR 전체 완료를 판단할 수 있습니다.

근거와 세부 작업 범위는 [남은 작업 조사](14-research-remaining-work.md), 기존 수정의 검증 결과는 [구현 보고서](12-report-remediation-loops.md)와 [독립 리뷰](13-review-remediation-implementation.md)에 있습니다. 이 문서는 해당 조사 결과를 쉽게 풀어쓴 설명이며, 새 구현이나 검증 결과를 추가하지 않습니다.
