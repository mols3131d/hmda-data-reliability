# Inbox

Artifact는 `YYYY-MM-DD/` directory와 filename/frontmatter metadata를 기준으로 직접 찾는다. 이 README는 artifact index나 status projection으로 갱신하지 않는다.

Inbox 운영 규칙은 [`AGENTS.md`](AGENTS.md)를 따른다.
