## Confirmed Gap and Remediation

[Approval gate](../../openspec/specs/reliability-recovery-backfill/spec.md) requires execution request binding mismatch to be rejected before source processing. At the audited base, `ApprovedBackfillRequest` validated profile versus request, while `_ensure_approved()` validated approval versus proposal. Neither compared request table/year/file against the approved proposal.

A valid request/profile with changed scope and a missing source reached `load_hmda_loans_partition()`. The three regression cases returned source-derived `BackfillValidationError` instead of the expected `ApprovalGateError`. This independently reproduces the ordering defect without mocking domain behavior. Existing scope-bearing content identity still blocked target mutation; this is not evidence of an unauthorized mutation or AI authority bypass.

The fix compares the three scope fields in `_ensure_approved()` before staging. The same regression now passes and existing module cases remain green. Canonical behavior is unchanged; the active Change retains `skip_specs: true` because implementation is restored to its existing contract. Local RED/GREEN logs: `.local/pr239/scope-red.log` (3 failed) and `.local/pr239/scope-green.log` (25 passed).

## Fixture and Composition Audit

Production `evaluate_null_spike_vertical_slice()` creates the validated candidate, constructs `RecoveryProposal`, calls externally supplied `approve`, and executes recovery. The real system E2E invokes this owner with actual dbt validation/promotion callbacks. Manual proposal fixtures in other tests therefore do not stand in for a missing production workflow. Human approval is intentionally external; a new UI or authority service is outside this MVP.

The live CLI constructs representative profiles and invokes production detector/draft APIs, then the actual review service/provider/store. This satisfies the bounded review input boundary; it does not independently prove ingestion, which has separate real-data proof. No requirement mandates one global fixture spanning every acceptance domain or Airflow orchestration of the control plane.
