# Language Policy

기본 언어는 한국어다.

## Exceptions

- 문서 제목, H1\~H3, 파일명, 경로, 기술적 식별자는 영어를 사용한다.
- 코드, API, 스키마, 설정값 등 기존 계약은 원래 표기를 유지한다.
- 외부 규격이나 자동화가 요구하는 표기를 우선한다.

## Bilingual Terms

한국어만으로 충분하면 영어를 병기하지 않는다. 식별·검색·의미 구분에 필요한 경우에만 처음 한 번 병기한다.
