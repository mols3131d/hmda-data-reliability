# Language Policy

Repository text의 기본 언어는 한국어다. 한국어가 자연스러우면 한국어를 사용한다. 한국어가 어색하고 영어가 자연스러울 때만 영어를 사용한다. 한국어와 영어가 모두 어색하면 한국어를 사용한다.

## English-required Surfaces

| Surface | Rule | Note |
| --- | --- | --- |
| Document title, H1–H3 heading | English | H4 이하 heading은 기본 언어 규칙을 따른다. |
| Field name, label | English | |
| Metadata key와 짧은 structured value | English | 문단 수준의 긴 value는 prose로 취급한다. |
| File name, directory name, repository path | English | |
| Code identifier, API name, CLI name | Declared identifier | 식별에 필요한 이름은 선언된 표기를 유지하고 주변 설명은 기본 언어 규칙을 따른다. |
| Established technical term | Korean or English | 기본 언어 규칙을 따른다. |

## Prose

설명 본문과 긴 서술형 text는 기본 언어 규칙을 따른다. Technical topic이라는 이유만으로 본문 전체를 영어로 바꾸지는 않는다.
