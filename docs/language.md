# Language Policy

기본 언어는 한국어다.

## Exceptions

- 문서 제목, H1~H3, 파일명, 경로, 새로운 기술적 식별자는 영어를 사용한다.
- 기존 코드·API·스키마·설정값 등의 표기는 유지한다.
- 외부 규격과 자동화의 표기 요구사항을 우선한다.

## Bilingual Terms

영어 병기는 식별·검색·의미 구분에 필요한 경우 처음 한 번만 사용한다.
