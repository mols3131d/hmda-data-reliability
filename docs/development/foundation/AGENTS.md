# Foundation Documentation Instructions

이 directory의 문서는 foundation에서 어느 정도까지 다룰지 정리한 작업 중인 초안이다.

## Status

- 문서는 확정된 제품 명세나 runtime contract가 아니다.
- foundation의 목적, 범위, layer 경계와 후속 작업 후보를 간단히 기록한다.
- 요구사항과 설계가 바뀌면 문서를 수정한다.
- 현재 내용과 구현이 다르면 문서에 맞춰 구현하지 말고 canonical source와 OpenSpec을 확인한다.

## Lifecycle

- 이 directory의 문서는 앞으로 계속 수정될 수 있다.
- 더 이상 필요하지 않으면 삭제할 수 있다.
- 장기적으로 보존할 가치가 확인된 경우에만 별도 archive 위치로 보관한다.
- 삭제 또는 archive 전환 전에는 문서가 다른 문서의 필수 근거로 사용되는지 확인한다.

## Writing Rules

- KISS와 DRY를 따른다.
- 한 문서에는 하나의 주제와 책임만 둔다.
- 확정된 규칙, 가설, 미결정 사항과 후속 후보를 구분한다.
- 세부 runtime contract와 완료 조건을 이 directory에 복제하지 않는다.
- Foundation bundle 밖의 문서에서 이 directory의 문서를 링크하지 않는다.
- 문서 상태가 초안임을 숨기지 않는다.
