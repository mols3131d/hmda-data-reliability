# 평가 보고서 생성 구현

## Context

- 파이프라인의 안전성과 신뢰성을 점검하기 위해, 시뮬레이션한 합성 에러 파티션들이 의도대로 탐지되었고 올바른 조치가 수행되었는지에 대한 전체 리포트를 생성해야 합니다.

## Goal

- 로컬 시나리오 실행 결과를 수집해 최종 품질 및 해결률을 담은 `evaluation_report.md` 파일 자동 작성.

## Non-Goal

- 동적 UI 기반의 웹 모니터링 대시보드 구축

## Scope

- 각 합성 케이스(이상치 주입 파티션)에 대한 탐지 여부 및 에이전트 해결 성공률 통계
- 마크다운 형태의 결과 보고서 생성 포매터

## Todo

- [ ] 평가 대상 시나리오 결과를 수집하여 통계를 내는 Evaluation 엔진 작성
- [ ] 수집된 결과 및 정량 지표를 정리하여 마크다운 파일로 내보내는 리포트 작성 기능 구현

## Acceptance Criteria

- 전체 파이프라인 시나리오 테스트 실행이 끝나면 디렉터리에 `evaluation_report.md` 문서가 생성되고, 각 합성 케이스의 탐지 및 조치 성공 여부가 명확히 표시되어야 합니다.
