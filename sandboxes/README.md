# Sandbox

이 디렉터리는 프로젝트를 이해하는 과정에서 생기는 **이해의 병목**을 해소하기 위한 공간이다.
production 코드를 작은 입력과 관찰 가능한 단계로 실행하며, 데이터의 변화와 예외를 직접 확인한다.

## 파일 규칙

- `sandbox_` 접두사가 있는 파일은 사용자가 직접 실행하는 **샌드박스 엔트리**다.
- `_mo.py`로 끝나는 파일은 Marimo 노트북이다.

엔트리 목록은 다음 명령으로 찾는다.

```bash
rg --files sandbox | rg '/sandbox_'
```

## 작성 원칙

1. production 로직을 복사하지 않고 `src/project_pivot`에서 직접 import한다.
2. 작은 fixture와 단계별 출력으로 입력, 변환, 결과, 예외를 눈으로 확인할 수 있게 한다.
3. 실험 결과는 `tmp/`에만 기록하고 production 데이터와 설정을 변경하지 않는다.
4. 샌드박스에서 확인한 사실과 production 코드의 동작을 구분해 기록한다.
