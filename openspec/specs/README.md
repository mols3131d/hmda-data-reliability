# OpenSpec Specs

`openspec/specs/`는 현재 canonical capability Spec을 저장한다.

Spec은 프로젝트 phase, 구현 작업, 임시 Change가 아니라 지속적인 시스템 capability를 나타낸다.

- Spec ID에는 capability가 필수다.
- capability만으로 충분하면 이름을 거기서 끝낸다.
- extensions는 안정적인 추가 구분이 필요할 때만 사용한다.

공통 구조와 이름 규칙은 [`../README.md`](../README.md), 작성 규칙은 [`../config.yaml`](../config.yaml)을 따른다.
