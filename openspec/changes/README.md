# OpenSpec Changes

`openspec/changes/`는 진행 중인 OpenSpec Change와 완료된 archive를 저장한다.

Change는 하나의 검토 가능한 변경 목적을 가진다.

- Change ID에는 short-title이 필수다.
- capability는 분류에 도움이 될 때만 포함한다.
- short-title은 이번 Change의 구체적인 의도나 결과를 짧게 표현한다.

공통 규칙은 [`../README.md`](../README.md), artifact 작성 규칙은 [`../config.yaml`](../config.yaml)을 따른다.
