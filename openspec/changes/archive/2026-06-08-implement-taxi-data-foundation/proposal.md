## Why

- 품질 이상 탐지기(Detector) 및 에이전트(LangGraph)의 비정상 탐지 시나리오를 로컬에서 안정적으로 검증하기 위함입니다.
- 이를 위해 실제 물리 데이터(Parquet, CSV)를 기반으로 데이터 결함을 주입한 5가지 합성 이상치 파티션 데이터셋을 DuckDB에 로드하고 쿼리할 수 있는 데이터 신뢰성 검증의 기초 토대를 마련합니다.

## What Changes

- **DuckDB 연결 및 raw 테이블 초기화**: NYC Taxi 데이터를 담을 로컬 DuckDB 연결 관리와 raw 테이블 생성 로직을 정의합니다.
- **원본 데이터 적재(Ingestion)**: `data/raw/tlc` 경로의 지정 연도 옐로우 택시 Parquet 데이터와 존 룩업 CSV 파일을 읽어 DuckDB로 로드하는 모듈을 구현합니다.
- **합성 데이터셋(Synthetic Cases) 생성**: 정상 데이터 외에, 의도적인 품질 이상이 주입된 4가지 변형 파티션 파일(행 유실, Null 급증, 스키마 변형, 지연)을 생성하여 디스크에 개별 파티션으로 저장하는 기능을 개발합니다.
- **단위 테스트 및 검증**: 생성된 5가지 정상/이상 파티션이 DuckDB 내에 개별적으로 적재되어 정상적으로 개별 쿼리가 수행되고 각 결함 조건이 올바르게 나타나는지 검증하는 테스트 코드를 구축합니다.

## Capabilities

## Impact

- **신규 모듈 추가**: `src/project_pivot/` 아래에 DuckDB 관리 및 합성 데이터셋 생성 모듈 추가.
- **테스트 환경**: `tests/` 아래에 파운데이션 적재 및 합성 데이터 검증 테스트 추가.
- **데이터 저장소**: 로컬 DuckDB(`.db` 또는 인메모리) 연동 및 테스트용 변형 파티션 파일이 로컬 디스크에 저장됨.
- **다운스트림 파이프라인**: 3단계 Ingestion 오버라이트 및 4단계 dbt 모델링의 입력 소스로 직접 연계됨.
