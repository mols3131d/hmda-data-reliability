## Tasks

[변경 명세](specs/reliability-agentic-review/spec.md)와 [설계](design.md)를 기준으로 구현한다. 교체 전 합성 다중 턴 사례의 반환값과 전체 로컬 산출물 크기를 확보해 기록 작업에 사용한다. [테스트 설계 기준](../../../docs/development/test-design.md)

- [ ] 고정 입력과 승인된 읽기 전용 조회를 처리하는 사고 조사 그래프를 연결한다.
  - **Test first** 고정 모델·시계로 보고서만 반환한 조사, 복수 도구 요청의 순서, 도구 한도 초과·정확한 한도, 반복·잘못된 조회, 프롬프트 크기 상한과 범위 밖 조회 차단을 검증한다.
  - **Done when** `investigate_incident`의 사실과 실패 상태가 명세와 일치한다. 한도를 넘긴 도구나 중복 요청은 실행되지 않고, 정확히 도구 한도에 도달한 뒤 남은 턴에서 도구 없는 보고를 요청할 수 있다.

- [ ] 참조형 로컬 저장과 기록 기반 재현을 연결한다.
  - **Test first** 빈 본문·잘못된 JSON·도구 전용 응답, 늦은 응답과 최종 파일 저장 실패의 경로를 검증한다. 고정한 과거 파일을 읽고 저장 실패를 기록만으로 재현한다.
  - **Done when** 앞서 저장한 원문과 조회 결과를 최종 기록 실패 뒤에도 회수한다. 필수 저장이 기한 안에 완료될 때만 성공을 반환한다. 공개 결과를 참조에서 복원하고, 재현의 외부 호출은 0회이며 부족한 기록은 재현 불가로 보고한다. 교체 전과 같은 다중 턴의 전체 저장 바이트는 줄고 같은 결과와 근거를 회수한다.

- [ ] Codex 구독 OAuth 어댑터를 우선 연결한다.
  - **Test first** 모의 프로토콜로 계정 유형·격리 확인 실패, 미수락·수락 불명확 단절, 불일치·중복 이벤트, 기한 초과와 취소를 구별한다. 검증 없는 환경으로 근거를 보내는 시도와 수락 불명확 재시도는 0회여야 한다.
  - **Done when** ChatGPT 구독 계정의 실제 합성 조사에서 한 턴이 조회를 제안하고 새 스레드의 후속 턴이 해당 관찰값을 사용한다. 조사·시도·스레드·턴을 기록하고 범위 밖 접근을 거절하는 실행 경계를 확인한다.

- [ ] Ollama 호환 연결과 제공자 선택을 새 계약으로 연결한다.
  - **Test first** 주입 어댑터와 호환 설정을 동시에 전달하는 기존 API, 명시적 CLI 제공자, 호환 URL, 키만 설정한 기본 호출, 충돌하는 선택을 대조한다. 호환 연결의 기존 타임아웃·연결·5xx 재시도 수를 회귀 검증한다.
  - **Done when** 새 그래프에서 명시적으로 선택한 Ollama가 조회 제안과 구조화된 결과를 반환한다. 기존 OpenAI 호환 설정은 동일하게 사용 가능하고 다른 제공자의 인증·모델 기본값이 섞이지 않는다.

- [ ] 위임의 백필 전제 검사와 승인 결과를 새 조사 실행에 연결한다.
  - **Test first** DB 연결 누락·대상 또는 범위 불일치는 모델과 복구 호출 0회로 검증한다. 유효한 승인 요청을 제공해도 조사 실패나 기한 경과 시 복구는 0회여야 한다.
  - **Done when** 승인 백필 연결 누락은 조사 전에 `blocked`를 반환한다. 실행 가능한 요청은 기존 승인 실행기가 검증하고, 실행 결과의 `partial`·`not_reported`와 스키마 복구 연결 의미를 보존한다.

- [ ] 평가 CLI와 Langfuse 관측을 같은 조사 실행에 연결한다.
  - **Test first** 허용·미허용 합성 표식이 섞인 Dataset에서 실험·모델 호출 0회와 종료 코드 `2`를 확인한다. Prompt 조회 실패, 결과 누락·중복, oracle 비노출, 허용되지 않은 원격 본문과 관측 장애 시 재호출 차단을 검증한다.
  - **Done when** 기존 Dataset 항목과 실제 조사·턴·관측 ID를 연결하고, 합성 실행에서 해당 원격 기록을 다시 조회할 수 있다. 로컬 결과와 SDK 전송, 원격 조회의 근거를 분리해 기록한다.

- [ ] 기존 사고 조사 실행부를 교체하고 운영 진입점을 정리한다.
  - **Done when** 공개 사고 조사, 위임, 합성 평가가 같은 그래프를 사용하며 옛 모델·도구 루프가 제거된다. 기존 사고 조사·Runtime AI 회귀와 과거 파일 읽기가 통과한다. 도메인·사용 가이드에서 선택 방법, 결과 해석과 Codex·Ollama 검증 범위를 확인할 수 있다.
