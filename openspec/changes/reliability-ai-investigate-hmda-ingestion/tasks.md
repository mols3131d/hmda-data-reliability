## Tasks

구현의 계약은 [적재 조사 명세](specs/reliability-ai-ingestion-investigation/spec.md)와 [설계](design.md)다. 모델 분기와 기록을 연결할 때는 [사고 조사 교체 Change](../reliability-ai-replace-investigation-runtime/proposal.md)의 공용 실행 계약을 사용한다. [테스트 설계 기준](../../../docs/development/test-design.md)

- [ ] 원천 스냅샷을 고정하고 지정 범위의 준비 판정을 계산한다.
  - **Test first:** 고정 CSV·Parquet의 파일 집합·누락 열·대상 행 수를 기대값으로 사용한다. 파일을 하나 지정해도 적재기가 검사하는 전체 파일의 필수 열을 확인한다. 전체 발견 후 빈 원천의 `blocked`와 발견을 마치지 못한 원천의 `needs_human`을 대조한다.
  - **Done when:** 정상·확정 위반·미확인 입력이 각각 `ready`, `blocked`, `needs_human`을 반환하고, 다른 버전의 관찰값을 섞을 수 없다. 임시 Bronze와 원천은 조회 전후 동일하다.

- [ ] 적재 판단과 조회 정책을 공용 조사 그래프에 연결한다.
  - **Test first:** 공용 제공자 형식의 고정 응답으로 초기 근거가 다른 입력에서 서로 다른 조회를 선택한다. 규칙과 다음 조치가 확정되면 모델 0회, 제안 ID 불일치나 복수 요청이면 추가 조회 0회를 확인한다.
  - **Done when:** 적재 판정과 모델 권고를 구분하고 허용한 도구·인자·근거 범위만 조회한다. 후속 판단이 필요하면 기록된 제안 ID에 대응하는 관찰값을 다음 턴에 사용한다.

- [ ] 허용된 Airflow 실행의 단계 결과를 읽어 사후 보고를 반환한다.
  - **Test first:** Airflow 응답 형식의 고정 데이터로 태스크 상태, 다른 실행·시도의 asset 기록, 실제 입력 버전의 일치·불일치·미확인을 검증한다.
  - **Done when:** 지정된 실행의 단계 상태와 확인된 갱신 근거를 구분해 반환한다. 증거가 부족한 경우 행 수와 입력 일치 여부의 미확인을 보고하며 조회 과정에서 상태 변경 요청을 보내지 않는다.

- [ ] 공용 실행 기록에서 적재 근거와 실패 인계를 회수한다.
  - **Test first:** 고정 시계로 기한 이후 응답을 받아 해당 응답은 보존하고 추가 조회는 0회인지 확인한다. 프롬프트나 모델 장애도 실패 인계로 이어지는지 검사한다.
  - **Done when:** 조사 ID로 초기 검사·실행 조회, 턴·시도 기록, 기한 전에 확정한 판정과 실패 이유를 회수한다.

- [ ] 중단 기록을 연결하고 조사 결과를 오프라인에서 재현한다.
  - **Test first:** 저장된 기록에서 정상·기한 소진·저장 실패 이후 결과를 다시 계산하고 필수 기록 누락과 프로세스 중단 뒤 새 조사 요청을 검사한다.
  - **Done when:** 재현 ID에서 원 조사의 판정·인계·종료 사유를 다시 계산한다. 원천·Airflow·모델·프롬프트 조회와 원격 관측은 모두 0회다. 중단 뒤 새 조사는 이전 조사 ID를 참조한다.

- [ ] 적재 조사 기록을 공용 Langfuse 관측에 연결한다.
  - **Test first:** 테스트용 exporter로 합성 사례의 허용 필드와 비합성 입력의 원격 본문 제외를 확인하고 전송 실패를 재현한다.
  - **Done when:** 모델을 호출한 조사는 실제 프롬프트 버전과 관측 결과를 같은 조사 ID로 연결한다. 전송 실패는 로컬 결과에 영향을 주지 않으며 추가 모델 호출은 0회다.

- [ ] 운영자가 준비 조사부터 실행 결과 확인까지 재현할 수 있는 사용 경로를 제공한다.
  - **Done when:** 실제 로컬 원천과 고정 응답 모델로 준비 조사·인계를 실행하고, 지정 DAG 기록과의 연결 및 오프라인 재현을 통합 검증한다. 기존 적재·Airflow 테스트를 통과한다. 운영 가이드와 관련 도메인 문서에 호출법, 결과 해석, 검증된 실행 범위를 기록한다.
